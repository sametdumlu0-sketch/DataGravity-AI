## 🌟 Overview

**DataGravity Analyst** bridges the gap between raw data and executive decision-making. Designed with a **Vercel & Linear-inspired dark glassmorphism design system**, it empowers data scientists, executives, and business analysts with autonomous data cleaning, hands-free voice control, 3D spatial data rendering, and multi-agent AI synthesis.

---

## ✨ Key Features

### 🤖 1. Multi-Agent AI Data Council
* **3x Autonomous AI Agents:** Synthesizes insights simultaneously from a **Data Scientist**, a **Business Strategist**, and a **Data Quality Auditor**.
* **Consensus Engine:** Resolves conflicting metrics and provides a unified executive decision framework.

### 🌌 2. Interactive 3D Data Universe
* Renders high-dimensional dataset matrices into an interactive, spatial **3D Canvas point cloud**.
* Visualizes data density, cluster distributions, and anomaly gravitational fields in real-time.

### 🩺 3. Autonomous "Data Doctor"
* **One-Click Data Cleansing:** Automatically detects missing values, duplicate records, structural anomalies, and skewness.
* **Auto-Imputation:** Provides AI-driven data repair strategies before running analytical models.

### 🎙️ 4. Full Hands-Free "Jarvis" Voice Copilot
* Integrated with Web Speech API for bi-directional voice command interpretation.
* Speak naturally (*"Show sales trends for Q3"*) to filter data, adjust charts, and hear spoken executive summaries.

### 📱 5. 30s AI Data Reel Generator
* Converts complex analytical findings into a **9:16 vertical story format** (Reels/Shorts style) with 5-second animated metric slides for instant executive or social media sharing.

### 🔮 6. What-If Scenario Simulator & Root Cause Engine
* Dynamic parameter manipulation sliders to forecast revenue, churn risk, and operational bottleneck shifts.
* Automated statistical anomaly detection with root cause attribution.

### 📊 7. Enterprise Export Engine & Command Palette
* **One-Click Native PowerPoint (.pptx):** Generates fully editable, styled presentation decks powered by `pptxgenjs`.
* **Keyboard-First Design (`Ctrl + K` / `⌘K`):** Instant Command Palette to trigger actions, switch views, and search insights without taking hands off the keyboard.

### 🔐 8. Authentication & Rate-Limit Resilience
* Built-in JWT authentication, user registration, saved analysis history, and Free/Pro tier simulation.
* **Exponential Backoff & Key Rotation:** Graceful handling of API rate limits (429 Rate Limit) with friendly fallback UI states.

## 🛠️ Tech Stack

### **Frontend**
* **Framework:** React 18 (TypeScript, Vite/CRA)
* **Styling:** Tailwind CSS (Custom Glassmorphism, Bento Grid layout)
* **Animations:** Framer Motion (`motion.div`), Lucide React Icons
* **Data Visualization:** Recharts, HTML5 Canvas 3D, Three.js
* **Documents & Media:** `pptxgenjs` (PowerPoint engine), Web Speech API

### **Backend**
* **Runtime:** Node.js, Express.js (TypeScript)
* **AI Engine:** Google `@google/genai` SDK (`gemini-3.6-flash`)
* **Security:** `jsonwebtoken` (JWT), `bcryptjs` password hashing, CORS
* **Architecture:** RESTful Endpoints with Exponential Backoff Retry & Rate-Limit Resilience
